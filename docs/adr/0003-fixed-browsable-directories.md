# 浏览范围限定在固定目录集合，而非整个设备文件系统

Android 的分区存储限制（Android 11 及以上）会阻止非 root 状态下 ADB 访问任意路径——尤其是其他 App 存放在 `Android/data` 下的私有数据，而且这个限制在不同系统版本、不同厂商定制系统上表现还不一致。所以如果做成通用文件管理器那样的浏览器，会不可预测地撞上权限墙。我们决定只暴露一组固定的、已验证可用的目录（DCIM、Pictures、Movies、Download、Documents，以及一些常见社交 App 的公开媒体目录），而不是整个 `/sdcard/` 目录树。

**后果**：不在这些目录范围内的文件，用这个工具是访问不到的。但这符合实际使用场景（把手机上的照片和文件传出来），而不是做一个通用文件管理器。
